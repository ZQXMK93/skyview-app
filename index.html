Questions.

Is SkyView free?

Yes. Everything above is free, for as many players as you like. Pro is an optional one-time $5.

What do I need?

A free Hypixel API key from developer.hypixel.net, pasted into SkyView's Settings. Development keys expire every three days, so you paste a fresh one now and then.

Why does Windows or macOS warn me when I open it?

SkyView isn't code-signed yet. On Windows choose More info, then Run anyway. On a Mac, right-click SkyView and choose Open the first time.

Is my Minecraft account safe?

Profiles come from Hypixel's public API and SkyView only reads them. The Mods tab signs in on Microsoft's own page and keeps an encrypted sign-in token on your computer, nowhere else.

Does it work offline?

Looking players up needs the internet. The item list, NPCs and the local AI keep working offline once they've been downloaded.
